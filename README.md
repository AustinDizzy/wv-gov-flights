# wv-gov-flights 🏛️🛩️

a website (built w/ [Astro](https://astro.build)) to display trip, passenger, and invoice data from a [SQLite](https://www.sqlite.org/) database (via [Cloudflare D1](https://www.cloudflare.com/products/d1/)) in an enriched way -- with support for basic text searches and recorded flight path visualizations using [Leaflet](https://leafletjs.com/) -- of aircraft owned & operated by the [State of West Virginia's Aviation Division](https://aviation.wv.gov)

https://l.abs.codes/wv-gov-flights

### Data

Information has been sourced from public records and legal requests made under [W.Va. Code § 29B-1-1 (WVFOIA)](https://code.wvlegislature.gov/29b-1/). The intent is to keep the database updated on a semiannual basis as information is released.
